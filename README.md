# 📝 AI Resume Enhancer

🔗 **Live App:** [Try it here](https://ai-resume-enhancer.streamlit.app/)  


An **AI-powered Resume Enhancer App** built with **Streamlit**.  
This tool analyzes resumes, provides **ATS compatibility checks**, gives **section-wise feedback**, and even offers an **Auto-Enhancement feature** where GPT rewrites selected sections (or the entire resume) for better alignment with job descriptions.

---

🚀 Features

- **Resume Upload & Parsing**  
  Upload resumes in PDF format for instant analysis.

- **ATS Compatibility Check**  
  Detects issues like images, tables, font problems, missing sections, etc.  
  Returns ✅/❌ status with fix suggestions.

- **Resume Scorecard**  
  Multiple evaluation dimensions:  
  - Keyword Match Score  
  - Experience Relevance Score (AI-based)  
  - Skill Alignment Score  
  - Formatting Quality Score  
  - Overall Weighted Score  

- **Section-Wise Feedback**  
  NLP-powered detailed suggestions for:  
  - Skills  
  - Experience  
  - Education  
  - Projects  

## 🛠️ Tech Stack

- **Python 3**  
- **Streamlit** – UI & interactivity  
- **OpenAI GPT (via Groq API / OpenAI API)** – AI analysis & rewriting  
- **PDFPlumber** – Extract text from PDF resumes  
- **Plotly** – Visual Resume Scorecard
